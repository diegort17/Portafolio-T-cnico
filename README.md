# Portafolio-T-cnico
Perito en Electrónica y Dispositivos Digitales, interesado en la electrónica, el soporte informático y la automatización.
## Competencias técnicas
- Electrónica y soldadura de componentes.
- Mantenimiento y diagnóstico básico de computadoras.
- Redes informáticas y configuración básica de routers.
- Programación con Arduino/C++ y microcontroladores ESP32.
- Microsoft Office: nivel intermedio.
- Inglés: nivel básico.

## Proyectos destacados

### 1. Sistema de medición de distancia
Proyecto de electrónica con sensor ultrasónico y Arduino para medir distancias. Incluye el montaje del circuito, el programa y las pruebas realizadas.

**Tecnologías:** Arduino, sensor ultrasónico y componentes electrónicos.

[Ver repositorio de medición de distancia](https://github.com/diegort17/Medici-n-de-Distancia)

### 2. Cubo LED 5×5×5
Proyecto de electrónica digital que utiliza una matriz tridimensional de 125 LED y programación para crear diferentes patrones de iluminación.

**Tecnologías:** Arduino, LED, circuitos electrónicos y programación C/C++.

[Ver repositorio del cubo LED](https://github.com/diegort17/Cubo_Led_5x5x5)

### 3. Reconocedor de medicamentos con ESP32 e inteligencia artificial
Proyecto académico orientado al reconocimiento de medicamentos mediante un sistema basado en ESP32 e inteligencia artificial.

- **Tecnologías:** ESP32 e inteligencia artificial.
- **Desarrollo:** conexiones electrónicas, programación, base de datos, pruebas y documentación.
- **Evidencias:** documentación y fotografías del proyecto.

[Ver proyecto y documentación](https://github.com/diegort17/RECONOCIMIENTO-DE-MEDICINAS)
